# 数据闭环实操作业
## 一、数据源选择及简介
本次作业数据源选取婚姻家事、财富管理方向的公开专业书籍文本，一共采集10份独立文档。全部内容为公开出版物文字资料，合规可用，用于本次数据闭环练习。

## 二、数据采集方式
选取10本不同的婚姻家事、财富管理类专业书籍，提取书中对应章节文本，每本书单独保存为一份独立Markdown文件，得到10份原始文件。

## 三、数据清洗过程
本次数据清洗全部由AI Agent批量自动完成。
清洗内容：剔除书籍扫描导出带来的乱码、页码、页眉页脚、目录标注、多余空行；规整段落，去掉无关注释，只保留书籍正文内容，统一排版格式。

## 四、数据脱敏处理
本次脱敏由AI Agent批量统一处理完成。
将书中出现的真实人名、企业名称、具体地名、案例里当事人信息匿名替换：移除所有可识别的真实主体信息。

## 五、元信息（YAML）添加说明
本次所有文件的头部YAML元信息均由AI Agent批量自动生成并插入，包含数据来源、采集时间、文档类型、书籍主题与标签，完成标准化数据结构化处理。
